# 当前导弹模型、研究进展与未解决问题

快照日期：2026-10-16。本文件对应本次 GitHub 同步的工作区模型，汇总“比较148和118回放轨迹差异”“实现冻结撤锁与惯导外推”“研究燃气舵动力学模型”三个线程截至快照时已经保存的代码与结果。这里的导弹和飞机都是 War Thunder 游戏内单位，复现目标是游戏引擎行为。

源码、版本化运行数据、测试和本文件随源码提交；体积较大的 `outputs/`、原始回放和 datamine 输入单独作为研究快照归档。下文 `../outputs/...` 链接是归档解压到仓库根目录后的路径，不能仅凭源码分支中的链接推断原始数据已在 Git 中。完整研究归档保存在同一仓库的 [research-snapshot-20261016 分支](https://github.com/skyking882/missile_sim/tree/research-snapshot-20261016)，包含分卷、SHA-256 清单与恢复命令；本次最终回归见第 7 节。

## 1. 输入版本与证据边界

- 活动参数集是 **2.59.0.27**，由 [catalog](../config/missile_profile_catalog.json) 选择；冻结 datamine commit 为 `4ac255b829a27346b9300fccdc138362c2535fbe`。2.57.1.107 数据及历史 H2 算例保留，不能与活动版本混合标定。
- 2026-10-08 五场实战回放头解码版本是 **2.59.0.54**；它与现活动参数版本存在小版本差异，尚未消除这项输入不确定性。
- 导弹原生状态时钟是 **48 Hz**。控制时钟、保存状态、雷达实际接收新测量是不同事件。飞机速度优先采用原生位置/时间差分，避免把有编码上限的速度字段当成真值。
- 默认 surface 内核为单等效气动面、四元数姿态和俯仰/偏航转动模型；不是独立辨识的完整六自由度模型。核心只用 Python 标准库。
- 回放条件识别、代码回归、端点拟合和自主飞行复现分别报告。给模型输入回放完整观测状态，并不能证明普通导引头可以自主生成同一状态。

字段主张与证据等级继续以 [BLKX_EVIDENCE_LEDGER.md](BLKX_EVIDENCE_LEDGER.md) 为准；经验近似和未确定的映射保持 `assumed`，不由这次归档提升为已知游戏实现。

## 3. #118/#148：完整 rate 与捕获过程

详细公式、案例来源和历史版本比较见 [WT_RATE_RECONSTRUCTION_PROGRESS_20261016.md](WT_RATE_RECONSTRUCTION_PROGRESS_20261016.md)。当前结论如下。

`direction` 与 `rate` 导出均支持世界系表达，采用 `n_dot = n × w` 的符号约定。方向变化不能确定沿 LOS 的 `λ=n·w`；普通换坐标不能凭空生成独立 λ。一次 `Q*w_INS` 是有数据支持的端点操作线索，不能等同于已证明的正常坐标转换。

- 五场服务器数据有 501 次首次雷达截获，472 次目标仍存活。旧客户端与服务器的最后 INS/首 TRK 覆盖差别明显；服务器锚点间隔仍有 #118 的 2 tick 与 #148 的 3 tick。
- 160 项固定/共享变换候选、整场外层留出没有得到同时重构两例完整 rate 到量化精度的规则。pureQ 首步误差分别 **0.235979/0.573250 °/s**；共享 LOS 平面缩放改善平均误差和 #118，却恶化 #148。
- 普通成对更新支持 `w_next = w + g*c`，**g 约 11.23 s⁻¹**。108 对方向校正和 rate 增量可分辨样本均与留场增益相容；1221 对量化不可分辨记录不能用作“没有更新”的标签。1463 对保持记录支持世界系恒 rate 预测。
- `uid=49/eid=1719297` 的单 tick 反例，固定预测 **2h** 后方向误差 **0.000595°**，落入半格必要界 **0.003975°**。与两端之间额外一次预测相容，但原始记录没有证明内部保存阶段切换。没有新增 rate 门控，也未继续做 rate 行错位检验。
- 七个存活的大离轴 R-77-1 首捕（#118、121、134、136、145、148、161）检查历史估计、单次创新、早期增益、弹体角速度修正，以及 21 项捕获运算顺序与 21 项旧受限 direction 对照，均未得到共享前向首捕规则。
- 严格单 tick 存活普通更新中，捕获后 0–0.25 s 的 119 对记录不要求另一个早期 g；#148 在最初 250 ms 缺少合格成对记录，因此该结论不能补出它未保存的更新。
- 正确的弹体系运输只是世界系递推的等价表达；直接给 rate 加/减弹体角速度显著恶化结果。尚未排除的真实扫描、伺服、接受观测或内部阶段策略，需要额外状态证据。

**仍未解决的是首捕/复锁的完整 rate 初始化，以及实际接受观测的触发过程。** 反算隐藏方向或隐藏 INS rate 可以精确闭合已有端点，说明观测不足与解的不唯一；这种构造使用输出，不是在线预测，也不是识别成功。1 秒 memory 决定保持多久，不能解释第一条 TRK 为什么是该向量。

客户端和服务器在同物理 tick 的字段一致，只说明这两份已保存状态之间没有对应字段差异；它不排除两者共同上游的丢包、更新拒绝、内部微调或更早的状态缺失。当前数据没有实际接收观测/SNR/扫描/网络遥测，不能把任一种网络原因写成实锤。

主要证据：`outputs/wt_server_trk_innovation_audit_20261016/`、`wt_trk_uid49_phase_check_20261016/`、`wt_rate_transform_library_20261016/`、`wt_unified_frame_118_148_20261016/`、`wt_capture_policy_audit_20261016/`、`wt_capture_order_audit_20261016/` 各自 `results.json` 与分析脚本。

## 4. “实现冻结撤锁与惯导外推”线程当前结果

### 4.1 已进入模型的状态与积分修正

完整离架四元数、起控前被动姿态演化、冻结/撤锁/惯导预测、雷达保持时刻，以及 PID 积分输出调度均已在当前代码中。PID 的 `scheduled_terms` 保留每一步已经累积的积分贡献；本步新贡献乘 IAS 增益，P/D 使用当步增益，输出最后限幅。气动/力矩有效参数未因积分修正重新拟合。

保存的三案对照仅改变积分调度，使用各案各自相同的原始初态和输入：大离轴 #118 的局部过载缺口 **1.488→0.809 g**；另两枚小离轴导弹（第二场 #100/#118）前十秒位置 RMS **27.619→15.129 m**、**28.817→16.140 m**。小离轴 #100 的局部绝对过载误差略增；大离轴 #118 的自主首捕/整段轨迹仍明显不符。这是局部改善，不是整个高离轴问题已经消失。

证据：[积分调度结果](../outputs/wt_pid_integral_schedule_20261016/results.json)、[原生离架对照](../outputs/wt_native_launch_118_20261016/results.json)、[保持与雷达可达几何修正](../outputs/wt_148_coast_fullcone_fix_20261016/results.json)。不同历史表的窗口/初态不同，不把它们直接合成统一改善百分比。

### 4.2 起控前被动力矩：问题存在，共享修正未通过

按当前 **0.3 s 前零控制** 的设定，将服务器实测姿态、速度与角速度直接代入力矩模型，#118/#148 连续被动区间出现与角速度反向的缺口。这证实当前无控制姿态模型在这些区间不符；“零控制”是现采用起控设定，并非直接导出的 WT 舵量。

五场有 **116 枚、376 个**密集区间；其中 2 枚不同服务器载荷布局单列，主要队列为 **114 枚、369 区间**。每枚等权、整场留出、两轴共享；比较现有恢复+线性阻尼、稳健拟合与一个阻尼幂律候选。

| 留出指标，rad/s² | 当前模型 | 新线性 | 新幂律 |
|---|---:|---:|---:|
| #118 角加速度向量 RMS | 0.3182 | 0.3617 | 0.2403 |
| #148 角加速度向量 RMS | 0.3461 | 0.4858 | 0.3372 |

由训练侧选出的方案在全主要队列外测 **0.4818→0.5690 rad/s²**，40 枚改善、74 枚恶化。因此没有替换生产恢复/阻尼系数；不能从两个锚点推断通用倍率。当前三力矩系数原来自主动控制区间的共同标定，不构成被动段已验证的证据。

该审计在本快照前已经完成。它使用服务器实测姿态和位置差分速度比较速度增量，并以独立 `b7` 通道交叉对照；没有拿飞偏的模型轨迹倒推，也没有新增飞行或改生产参数。

| #118，5.042–5.313 s | 16.54° | 5.40 m/s² | 0.0869 |

### 5.2 燃气舵与燃尽重置

冻结气动、PN/PID、质量/推力与真实目标输入的对照已可运行。最大偏转 `.045 rad` 是当前工作假设；有效响应 `beta` 拟合不分别补造力臂/惯量，推力偏转替换轴向项，避免重复推力。

17 个预固定候选中选参案最好已试 `beta=.0053224 rad/(N·s²)`，但未稳定胜过无燃气舵基线。只用第一案燃烧期选参，第二案完整留出：

| 分支 | 选参案组合误差 | 留出案组合误差 |
|---|---:|---:|
| 无燃气舵 | 37.313 | 25.272 |
| 仅偏转推力，beta=0 | 43.775 | 14.659 |
| 偏转推力+所选 beta | 40.736 | 25.923 |

这是当前实验归一化组合目标，不能与其他历史表的单独位置 RMS 比较。另三案的迁移与逐案扫描也未得到同时改善轨迹、速度、完整姿态和角速率的共同关系；部分姿态改善与平动恶化并存。
