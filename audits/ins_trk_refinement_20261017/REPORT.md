# INS→TRK：量化、首捕/重获时序、普通反馈的联合核验

日期：2026-10-17。范围为War Thunder电子游戏回放状态重构。没有修改生产dev、原始WRPL分支或native解码器。实际为分开的程序与已完成GitHub Actions，不是AI subagent评审。本轮复用此前已经核验的原生导出子集，不重复声称重新解包所有WRPL。

## 1. 捕获横向保留0.8的证据增强，但不是逐条严格闭合

原候选244个相位零后续步事件中有79个R77；选样本用时序、timer和flag，不读取拟合残差。所谓零后续步仍以48m+1为候选捕获时刻，不能当作已观测到内部调用次数。

映射为w1=P_k(n1) Q1 w0，P_k(n)=kI+(1-k)nn^T。这里n1是当前保存目标方向，明确属于条件诊断，不是方向预测。rate格距q=15/32767rad/s，约0.02622872685deg/s。

比较两个编码单元假说：有符号向零截断，正整数k代表[k,k+1]、负整数代表[k-1,k]、零代表[-1,1]；最近舍入代表[k-.5,k+.5]。边界按闭区间进行数值兼容检查。Q和n固定在解码值，尚未整合其非线性量化不确定性。

R77留场拟合kappa：直接用解码值为0.797211–0.798980；同时把前后rate换成截断单元中心后为0.798963–0.800640。因此此前略低于0.8的拟合值，可以有明显的量化偏置成分，不能据0.798认定内部一定小于0.8。

在同一79个事件，固定0.8的完整rate RMS为0.028389deg/s；中心对中心RMS为0.025681deg/s。最小额外输出单元宽度LP允许旧rate在自己的单元中变化：

|---|---:|
| P0.8(n1)Q1 | 73 |
| P0.8(nPs1)Q1 | 73 |
| P0.8(g1)Q1，g为指向字段 | 67 |
| P0.8(n1)Q0 | 41 |
| Q1P0.8(n1)，直接复用相同数值的世界轴 | 27 |

最近舍入假说下P0.8(n1)Q1为61/79，而截断为73/79。这支持截断模型相对更相容，不足以证明WT具体序列化函数。LP中的逐事件可行值只是存在性见证，不能拿来当作前向预测隐藏状态。

kappa网格0.770到0.830，步长0.002：0.800与0.796均有73个可行事件，0.798为72个。因此不是凭可行计数唯一精确识别到0.800；它得到中心化回归、误差和兼容性的一致支持。

其中16个指向限幅事件，目标n轴为15/16相容，天线g轴为9/16。这支持横向是相对于目标/跟踪方向，不是直接相对于受限天线轴。但矩阵的表达顺序不等于内部调用顺序：P(n)Q=QP(Q^T n)，用正确变换过的轴在另一坐标系投影可以完全等价。

## 2. 固定全局相位主要是重获规律，不是所有首捕规律

对931个25→31保存边界逐一检查全部48种相位，不再只检验phase1：

| 集合 | 数量 | 保存区间包含48m+1 |
|---|---:|---:|
| 原501首次捕获 | 501 | 114 |
| 后续转换 | 430 | 430 |
| R77首次捕获 | 82 | 23 |
| R77后续转换 | 150 | 150 |

430个后续转换第一份31记录的模48相位只有1/2/3，数量分别204/214/12；原501首捕则分布于全部48个相位。由此不能把不符合phase1的387个首捕当成异常丢弃，更不能把所有雷达观测理解为1Hz。更合理的候选区分是首次进入条件满足时启动，以及后续搜索/重获的周期检查；具体游戏调用与网络保存机制还没有直接定位。

后续转换中fresh且两端flag0的条件映射误差：第一份31落在phase1为189例、RMS0.038940deg/s；落在phase2为175例、RMS1.147034deg/s；phase3为10例、RMS1.490004deg/s。它与首份保存前已经发生普通更新相容，但不能直接等同实际更新次数。

探索性地把同一个0.8映射用于此前相位假说覆盖不了的首捕：387个中386个freshflag0可以评分，Q-copy RMS0.370591deg/s，0.8映射为0.272087deg/s；其截断兼容为249/386。R77对应59例，映射中位误差0.022446deg/s，43/59截断相容，但RMS0.306979deg/s、最大2.269456deg/s，仍有明显反例。这说明交接映射可以比phase1时间假说覆盖更广，但不能对所有首份31记录不经普通更新就直接套用。

锚点离开31常发生于timer约1s，经29再到25或直接进入25；29→31也可以不在phase1附近。这要求区分短暂中间状态、完整进入25之后的周期重获，以及首次启动。首次phase日志的ticks_since_previous_loss只记录直接31→25，漏掉经过29的路径；修正版anchor_loss_boundaries_corrected.json记录每次离开31。这个诊断字段问题不影响捕获相位直方图、样本集合或rate映射评分。

## 3. alpha0.926主要是两tick端点关系

使用与上轮完全相同的5484对R77普通freshflag0记录，其中1/2/3tick间隔分别226/5041/217对。逐间隔全场诊断拟合得alpha分别0.842806、0.925726、0.951779；旧rate换为截断中心后仍为0.842931、0.925773、0.951857。各型号32189对也为约0.8443、0.9242、0.9584。

这意味着0.926稳定，很大程度上是由于样本以两tick为主；不能直接把它作为每个物理子步的alpha。逐间隔数字是诊断拟合，不是留场验证。

在看过这些诊断之后，另行声明并验证两个单参数端点权重：

alpha(T)=1-L/T，或者alpha(T)=T/(T+L)。

每次只用其他场次拟合，预测留出场；前者L=0.00307784到0.00314391s，后者L=0.00333085到0.00340538s。L是创新权重的时间尺度，不是已测得的真实传感器延迟，也不能直接拿来移动整条实体时间轴。

同一组5484对R77，保留原始rate作为预测初值和评分标签：

| 候选 | direction RMS/deg | 完整rate RMS/deg/s | Ps RMS/m |
|---|---:|---:|---:|
| 常数alpha | 0.00271280 | 0.03002982 | 0.75037449 |
| 1-L/T | 0.00265080 | 0.02942651 | 0.74171749 |
| T/(T+L) | 0.00265267 | 0.02944438 | 0.74200861 |
| 先前新速度隐式反馈线性化 | 0.00267607 | 0.02968968 | 0.74506095 |
| 每个h重复使用同一个当前指向 | 0.00505132 | 0.10173541 | 1.02046957 |

总体提升不大，但1tick子集有清楚改善：常数alpha的direction RMS0.00323673deg、rate0.03838956deg/s，变为1-L/T的0.00218565deg、0.02816212deg/s；Ps由0.80668m降至0.68067m。2tick基本不变；3tick方向与位置有所改善，但rate最大误差从0.24315略增到0.25122deg/s，未隐藏不利指标。

重复当前指向候选在每个留出折先扫alpha0.30到1.00网格再局部搜索，仍选择边界1.0且显著较差。可以反对“同一份端点角被原样反复用于所有隐藏子步”这个特定模型，不能反对真的存在多次变化中的隐藏测量。

全部普通模型仍输入当前保存指向g；g尚未被证明是独立目标测量。低误差仅约束端点关系，不能直接确定Ps、Vs、n、g的内部先后因果顺序。

## 4. 普通反馈是否能自行产生0.8

新的可检验推导是：先重置n=m，保留种子s=Qwold，以h预测后对同一m做一次普通反馈。小角度下：

wnew约等于s_parallel+[1-alpha(h)*h*g(h)]s_perp。

g(h)=1/(0.078525+h/2)，h=1/48。由于单h有效alpha不是0.926，而是约0.85，横向保留可能自然接近0.8。把其他场普通记录训练的参数直接转入捕获，避免重新拟合捕获比例；该检验的全部实际数字由CROSS_MODE_RESULT.md和bridge/bridge_summary.json给出。这个检验在量化、相位与普通权重结果之后提出，是探索性跨模式一致性测试。

其中当前n仍是条件重置射线；tau来自更早已有场次上的拟合，不能称为从头到尾完全盲测。线性映射的量化区间相容与精确球面反馈的解码值误差分别报告，不混称为完整非线性量化证明。即使测试成功，显式阻尼、等效反馈或输出处理仍可能在端点数据上简并；更不能凭这一步证明Q来自正确的被动坐标转换。

## 5. 尚未解释的六个R77量化不相容事件

固定Q1和n1、0.8、截断单元时，六例需要额外输出半宽约0.131到1.854个rate格。最大的两个是11.49.38场EID2826242/tick12337和EID2191362/tick11281。#118首捕也在六例内，但仅差0.131格，不能与接近两格的反例混为同等强度。

独立自身运动检查在六例上均支持正常标签间隔：位移梯形残差0.00246到0.00466m，反算时长比值约1.00003到1.00026；不能用“整枚实体其实走了两倍时间”来统一修复。Q/n量化、实际交接姿态、旧rate状态时刻与额外反馈仍需区分。没有根据这些输出误差重新筛选样本。
