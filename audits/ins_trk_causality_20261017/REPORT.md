# INS→TRK 机制与 Ps/Vs 因果关系：本轮结果

2026-10-17。项目为 War Thunder 电子游戏回放逆向，不涉及真实武器性能或设计。此轮没有修改生产 dev、原始 WRPL 或 native 解码器。无可用 subagent 调度器；实际执行的是四条分开的计算路线，以及两项后续检验，不是多位独立AI评审。

## 1. 最重要的修正：Q 关系不等于已证明的正常坐标转换

以未限幅的目标位置方向定义 nP=unit(Ps-p)，Rgeom=|Ps-p|，wgeom=(Vs-vm)×nP/Rgeom。不能使用 INS 中受限的保存direction代替nP。

在232个R77最后INS端点，保存raw rate与世界系wgeom完整向量误差：中位数0.028553°/s，95分位0.071981°/s，RMS0.244972°/s，最大3.410°/s。少数反例保留；不能称每条INS都严格几何闭合。

对同一组先乘Q，误差中位数约0.624°/s，RMS5.868371°/s。两个固定首次捕获锚点raw-vs-geometry误差分别0.033326°/s（#118）、0.036244°/s（#148）。因此“INS raw rate本来就在弹体系，乘Q只是正常转换到世界系”不是目前数据支持的直接解释。

TRK的220个fresh R77捕获端点中，raw rate的横向部分与世界系PV几何rate的RMS差为0.020694°/s；其完整向量RMS差1.170561°/s，主要是沿LOS分量（RMS1.170378°/s）。进一步支持原始INS和TRK字段不能简单按两个不同的普通坐标系解释。

数学上，正常的同一物理状态被动换坐标应同时变换n,w：

(Qn)·(Qw)=n·w。

如果原先w已经接近世界系几何量，只转w、而目标世界方向保持，那会改变物理向量及沿LOS分量。回放的Q规律可能对应状态初始化/重表达、不同子系统的取值契约或额外旋转；尚不足以判定是游戏源码bug。必须检查setter/getter或状态交接规则，而不是先给“正常坐标转换”结论。

## 2. 更接近直接捕获的子集出现约0.8横向保留

第一轮完成后发现固定phase1端点的横向保留接近0.8，随后提交FOLLOWUP_PROTOCOL再做探索性检验。不能把它称为首轮预注册或新的盲测。

固定候选捕获tick为旧INS之后首个48m+1。选择首个TRK端点恰好等于该tick、timer=0且前后flag0的244个事件，其中79个R77（来自四场，第五场无此类R77样本）。这只是“在该时序假说下无后续更新”的子集，不是直接观测到内部调用次数。

条件性重置映射：

s=Q_new*w_INS,
w_cap=[n*n^T+kappa*(I-n*n^T)]s。

本表使用当前保存n作为投影轴，**所以只识别rate交接映射，不是独立方向预测；n误差为0不能算成功证据**。

| 同一79个R77事件 | 完整rate RMS | 横向rate RMS |
|---|---:|---:|
| 只复制旋转种子，kappa=1 | 0.337965°/s | 0.337393°/s |
| 固定kappa=0.8 | **0.028389°/s** | **0.020493°/s** |
| 旧有效alpha0.926自反馈近似，kappa=1-0.926*h*g(h) | 0.037706°/s | 0.032184°/s |
| alpha1自反馈近似，kappa=1-h*g(h) | 0.060864°/s | 0.057606°/s |

h=1/48s，g(h)=1/(0.078525+h/2)。同组用其余场次拟合一个共同kappa、预测留出场，kappa落在0.797211–0.798980；完整rate留出RMS0.028359°/s，与直接固定0.8几乎相同。最大固定0.8残差仍为0.092929°/s，不声称逐点都达到严格量化可行性。

各型号244个事件上，固定0.8完整RMS0.069713°/s，最大0.869811°/s；这同样不是所有记录完全闭合。

直接用过去Ps/Vs重算几何rate代替保存rate并不能统一改善。79个R77中的旧几何种子对应RMS0.364530°/s，少数严重不自洽样本主导，虽然中位数仍较小。说明不能无条件丢弃已有rate记忆或把所有缓存当作同一时刻的独立真值。

kappa是捕获映射的横向保留比例，不是量测alpha。它与距离/Doppler配置里的0.8数值相同，仍不能据此证明来自同一参数或同一滤波器。其内部来源可以是显式投影/阻尼，也可以是等效的一次预测-反馈过程；本轮没有唯一恢复调用实现。

## 3. #148 不必靠改每个事件的增益：捕获后的更新次序确有影响

用同一个固定规则，#118两次捕获的候选tick等于首条TRK；#148首捕在14736→14739的包络内，候选捕获为14737，首条保存之前还包含14738和14739两次普通更新。

主检验只用旧Ps/Vs按CV构造每个子时刻目标射线，own位置在两端线性插值，Q按SO(3)插值，绝不读取当前Ps/Vs/n/w；4352个current-label污染检验通过。两个角输出/距离在这些实验中也没有作为隐藏创新反算工具。

### 3.2 #148 的较低误差属于另一个预先列出的候选，不能混成统一最好表

采用Qold种子、初始化后立即自反馈一次，再做两次普通更新，#148首次完整rate误差0.036938°/s、direction误差0.054325°、Ps误差11.879m。它解释了此前“只看一个初始化端点反馈”为什么可能失败，但不证明这个过程就是唯一实现。

把当前Ps/Vs反推回捕获时刻的另一项**诊断**，即使其方向按构造更接近答案，#148 rate误差反而约0.405°/s。不能因此假设当前Vs在捕获前就已经有效，也不能把当前Ps生成的方向当成独立新测量。

### 3.3 覆盖与反例

931个既有事件中，544个包络包含该固定phase，387个不包含；544里面只有114个来自原501首捕，其余430个为后续转换。因此不是501首捕全部重建。

## 4. Ps/Vs 要重新按“状态约束”研究，不能先当独立测量

fresh字段符合的几何关系仍应保留：

Ps=p+Rn,
Vs=(I-n*n^T)vm+d*n+R(n×w)。

本轮220个fresh R77端点的n/Ps夹角RMS0.001094°；上节的横向w与PV闭合也是独立代数关系。这里d是记录radial标量，不是无条件把closing取负。

这些关系不能区分“先更新PV再生成角状态”与“先更新角度/径向状态再生成PV”。更不能从PV恢复w的轴向分量，因为n×(lambda*n)=0。

### 同一批普通记录上的比较

从原始Linux导出重新解码原501案例前缀。仅取相邻code31、timer0、flag0、gap1..3tick、own梯形位移残差<0.5m。各型号指向角<45°共32189对，R77<54.9°共5484对。与旧报告5107对并非完全相同集合，不能直接当同分母的新旧改善率。

在同一5484对R77上，均按五场留一：

| 结构 | 位置RMS | 有效alpha |
|---|---:|---|
| 直接pointing+range | 1.020470m | 无 |
| 旧Ps/Vs预测+pointing校正 | 0.749714m | 0.924914–0.926732 |
| 旧n/w预测+pointing校正 | 0.750485m | 0.925215–0.926986 |
| 用当前Vs替代旧Vs的诊断 | 0.731890m | 0.873481–0.878190 |
| 不读取当前Vs的联立候选 | **0.745974m** | 使用上一行各留出场对应的训练alpha，不在测试场重拟合 |

最后一项不是取真Vs作弊，而是同时求解：

p_ang=Rot(-w_old*T)n_old,
w(n)=w_old+c(p_ang,n)/(tau+T/2),
V(n)=(I-n*n^T)vm+d*n+R(n×w(n)),
n=slerp(unit(Ps_old+T*V(n)-p),pointing,alpha)。

未知量n、w、V共同迭代，输入只含旧Ps/n/w、当前pointing/range/radial和own状态。当前Ps/Vs/n/w不在求解函数的输入集合内。R775484对全部收敛，最大固定点残差1.76e-16rad；direction RMS0.002723°、rate RMS0.030457°/s、Vs RMS6.2718m/s。

这不是更好生产模型的证明：位置信息改善很小，且仍然输入可能属于输出层的pointing/radial字段。各型号32189对还保留2个不收敛案例，整组位置RMS0.961560m、rate RMS0.628632°/s，明显不能称全组已成功。

### 为什么两种alpha可以给出相近结果

在共同切平面、小角度、两种基础预测近似相同，且只考虑角速度校正引起的横向速度变化时，令e为pointing创新，x为最终方向校正。使用新速度进行位置预测时：

x=alpha*e+(1-alpha)*T*g(T)*x。

于是同一个显式端点关系的有效权重为：

alpha_eff=alpha/[1-(1-alpha)Tg(T)]。

在主要的2tick间隔内，alpha约0.876可以对应alpha_eff约0.924。这是线性化结构解释，不是完整非线性更新的精确恒等式。它说明此前0.926的稳定拟合并不足以唯一识别内部alpha，Ps/Vs和角状态的保存/更新次序会改变读到的有效权重。

另一个仅用当前delta-rate描述pointing到n偏移的输出关系，R77位置留出RMS0.771087m，也接近上述结果；这同样是当前输出之间的关联，不是独立观测器。

## 5. 当前最有根据的组合机制与尚未闭合处

支持的候选组合是：INS输出受限指向、同时保有世界几何样式的rate；捕获切换到目标方向状态，rate按Q相关映射和近0.8横向保留进入新状态；首份保存可能晚于捕获，期间已发生普通反馈；fresh的Ps/Vs与角度/径向状态共同输出。

其中“Q相关rate重置”和“近0.8横向保留”已有可检验映射，但内部是主动重置、接口误解释还是保存阶段的变换尚未确认。Ps/Vs输出的几何约束确定性较强，计算先后仍可简并。大范围捕获失败仍集中在新方向来源及先验可信性、真实捕获时刻和隐藏观测更新上。

因此无需推倒原始解码、逐整数编码、普通held规律等已有证据；需要撤回的是把所有字段同时当独立真值，以及把低端点残差当成唯一因果顺序的结论。此轮没有重新研究或解决flag1 held的额外传播。
