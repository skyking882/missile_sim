# First attempt / retry schedule — fixed experiment

War Thunder replay software reconstruction. Source branch is based on remote dev7a1c0c6 plus the previous protocol. This experiment does not modify PN, aircraft/missile physics, control, original WRPL bytes, or frozen datamine. No new parameter fitting. Phase48m+1 is a hypothesis from existing recordings, NOT official engine source or a proven radar pulse frequency.

## Hypothesis
When enabled with an available in-range prior, perform the first search attempt immediately, independent of global phase. On failure, enter RETRY. Subsequent search attempts use global integer tick%48==1. After a success, ordinary accepted observations and short coasting recovery are not restricted to that search cadence. Only after the existing 48-tick hold expires do searches again use RETRY. Re-evaluate current geometry at each attempt; do not store earlier successful signal eligibility until the scheduled tick. Range exits/reentries do not automatically erase failed-attempt history. Duplicate same-tick calls never evaluate a new observation. A missing scheduled tick must be marked missing, not silently evaluated at the next saved record.

## Fixed checks
1. Independent state-machine tests: arbitrary-phase immediate success; first failure; periodic retries; same-tick idempotence; backwards time rejected; fresh-to-hold-to-fresh with no search delay; full expiration; range exits/reentry; no retrospective missed-slot evaluation; identical local age/different global epoch yields different retry times; future recorded TRK labels inaccessible.
2. Real #118/#148: reconstruct own and independent aircraft state at integer ticks, using known epochs, linear position interpolation and SO(3) attitude interpolation explicitly labeled offline reconstruction. At exact saved ticks cross-check source state. Search prior uses only latest available pre-capture Ps/Vs and elapsed time (conditional prior diagnostic, not autonomous data-link reconstruction). No use of new TRK n/w or TRK time to choose attempts. Saved TRK times are scoring labels only. Evaluate both frozen Gaussian width conventions7.5/15deg and RCS1/2m²; do not select a per-case best parameter. Keep all gate reasons.
3. Start from first available raw state at or after launch. Report first eligible attempt and failure from input history. If history is truncated after the hypothesized first attempt, mark incomplete and do not claim RETRY was independently established. Keep actual target mapping fixed from metadata, never nearest current Ps.
4. Do not repeat the error of forcing every first capture to phase1. For931 saved boundaries, recompute first/reacquisition phase overlap separately. Pure universal-periodic model is a negative control. Other first captures must remain an unverified generalization unless their initial attempt histories and independent target inputs are actually replayed. Synthetic scheduler tests do not validate387 real events.
5. The candidate can fail if a scheduled tick has insufficient signal, earlier immediate attempts already pass, or gate/phase assumptions do not explain the data. Publish failures and all fixed conditions. Use first preserved TRK time only as interval upper bound; do not tune to it.
