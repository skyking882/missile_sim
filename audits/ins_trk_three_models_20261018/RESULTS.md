# 三类机制实测：距离比例、向量混合、非正交转换

日期：2026-10-18。任务：War Thunder 电子游戏回放中的 INS→TRK 字段关系诊断。实际通过 GitHub 插件写入研究脚本，并运行已完成的 GitHub Actions；没有本地计算或 AI subagent 审查。原始 dev、WRPL 分支和 native 解析器未修改。

## 结论

三类方法已经在同一批冻结的931个边界上执行，不再只有协议。固定实际Q和当前条件n之后，允许任意正缩放可使原79个R77近交接端点中的相容数从73增加到77：#94、#102、#118首捕、#123可由某些正比例相容，#129和#112仍不能。

因此，用户提出的模长变化解释对四例仍有数学可能，不能直接断言都必须换一份种子。但现有距离比、共同向量混合和六种指定非正交转换，都没有在预注册的跨场模型选择流程中得到稳定优于基线的结果。不存在可据本轮结果直接替换dev的统一修复。

## 1. 样本、输入与比较口径

协议在本轮评分前已经存在：d871f93fae503f4c3ef7b84267f77bba652b032c 的 audits/ins_trk_three_models_20261018/PROTOCOL.md。输入为此前成功的 handover run39100358600，artifact12126670224，内含931个原始回放派生边界。每个任务验证完整127文件manifest，没有重新解包全部WRPL，也没有新增盲测场次。

主组：244个既定phase1、fresh、两端flag0候选近交接端点，其中79个R77。广组：全部931个边界，含501首捕、430后续转换；R77共232个。组间重叠，不能加总为独立样本。

基线：w_pred=D_.8(n_new) Q_new w_old，D_k(n)=kI+(1-k)nn^T。rate为native rad/s，表格转deg/s。rate量化步长15/32767rad/s，约0.0262287deg/s。量化假说为三分量signed向零截断，零单元[-1,1]，其他符号用对应单侧整格闭区间。

当前n与新range明确是条件输入，不是已恢复的独立雷达测量。候选构建不读取当前目标Ps/Vs、当前rate；每个家族931个NaN污染隔离检查。旧Ps/Vs也可能是缓存；Q、n和距离/PV辅助量固定在解码值。因此单元相容只是条件下存在隐藏rate值，未包含全部非线性量化不确定性。

每个留出场次/型号从其他场次近交接样本拟合一个系数，并只依据训练误差选择家族内候选，基线也参与竞争。同型号训练例少于10时使用其他场次全部型号并标注。R77各折无需该回退。选出的候选与系数原样用于该留出场次的近组及广组。没有逐事件挑最好候选。

全部固定候选和单独候选跨场拟合成绩也保留；看到留出成绩后选出某一个较优候选，只能作为后续线索，不能伪称主流程已经成功选中它。

## 4. 第一类：实际距离比没有解释所需缩放

距离输入分别为缓存旧R、旧Ps几何距离、旧Ps/Vs预测到新自身位置的距离、新记录R。四种比值、各自倒数，再分整体/横向作用，16种。另有从基线向每种变体插值的系数beta∈[0,1]，在其他场校准。

关键反例#94：在指定八个比值中，最大是新R/旧PV预测距离=1.041107；但实际Q下完整rate单元至少要求rho=1.067940。比值本身不够，beta∈[0,1]的部分修正也不可能超过这个最大值。因此这些指定距离比作为整体缩放无法修好#94。

对79例直接施加缓存Rold/Rnew：整体缩放RMS0.103239deg/s、60/79相容；仅横向缩放RMS0.077255deg/s、62/79相容，均明显差于基线。旧新距离不一定是同一阶段/同一缓存语义，这是失败的可能解释，但不是已证实原因。

仍有一个小线索：单独考察缓存Rold/Rnew的横向部分修正，其其他场训练beta约0.045–0.057，RMS为0.02816798deg/s、74/79相容，修好1例且未引入新失败。但家族模型选择在不同训练折没有稳定选择这一结构，主比较仍是73/79且RMS略差。这是约0.8%的局部RMS改善，不是统一机制，尤其没有解决#94/#129/#112。

## 5. 第二类：共同几何rate混合没有稳定获益

候选u来自旧Ps/Vs几何、半间隔/整间隔旧PV推进，或当前条件n/R与旧Vs；分别在Q前/后混合。新Ps/Vs、当前rate均不进入构建。

固定beta=.2时，旧几何/半间隔/整间隔的Q前混合RMS分别0.07029/0.07677/0.08414deg/s；Q后混合约0.354–0.356deg/s，明显破坏已匹配例。允许其他场拟合后，不少权重退到接近零，主选模结果0.02862064deg/s、72/79。

单独的“当前条件射线＋旧Vs，在Q前混合”经其他场拟合可把RMS降至0.02700482deg/s，但仍是73/79：修好一个旧失败，同时制造一个新失败。它的当前n属于条件输出，不是独立观测；不能把低RMS当作已恢复的新传感器通道。其他场只按训练集选择结构时也没有稳定选中它。

不能排除混入另一份尚未识别的状态，但这次八种有明确旧输入来源的共同混合规则没有给出统一修复。

## 6. 第三类：指定的Euler/极坐标转换不受支持

按native Q=Ry(heading)Rz(pitch)Rx(bank)推导角参数导数到机体系角速度的Jacobian；以150组独立有限差分验证。比较旧/新Jacobian及其逆，再测试极坐标yaw角变化率的cos(elevation)度量及其逆。没有任意拟合3×3矩阵。所有931例均未触发奇异性/退化回退。

固定完整Jacobian或其逆在79例上RMS约1.576–2.212deg/s，只有2–3例单元相容。极坐标度量及其逆为0.2531/0.5225deg/s，48/45例相容。允许从原基线向这些变换作很小插值后，系数缩得很小，但主选模结果仍为0.02939432deg/s、70/79。

结果反对“保存rate只是漏做这六种之一的完整Euler/极坐标转换”这一具体解释，不等于排除了所有非正交转换或状态依赖矩阵。
