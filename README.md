# missile_sim

[English](README.en.md)

一个用 Python 写的战争雷霆空空导弹飞行仿真器。

这个项目**基于战争雷霆现有空空导弹部分参数和游戏实验做的半经验半数据驱动动力学模型。**

---

## 能做什么

目前模型包括：

- 三维导弹与目标运动
- 5 自由度动力学：三维平动 + pitch / yaw
- 随 Mach 数变化的阻力
- 迎角相关的升力和附加阻力
- 四元数姿态积分
- 比例导引（PN）
- 中远程爬升制导
- 大离轴发射初始转向
- PID 自动驾驶仪
- 舵机动态
- 近炸引信和触地事件
- 固定步长 RK4 积分
- 本地网页 GUI
- CSV / JSON 遥测导出

暂时没有 roll。

## 快速开始

需要 Python 3.10 或以上。

仿真内核本身只使用 Python 标准库。

```bash
# 先跑回归测试，确认环境正常
python3 scripts/run_test_functions.py

# 打开 GUI
./run_gui.sh
```

Windows：

```bash
run_gui.cmd
```

也可以把 `python3` 换成：

```bash
py -3
```

GUI 只监听本机的 `127.0.0.1`，不需要联网。

启动后会扫描 `missiles/` 里的导弹参数文件。选导弹、设置发射条件，然后直接运行即可。

结果包括：

- 可旋转的三维弹道
- 速度、过载、迎角等遥测曲线
- JSON 和 CSV 数据导出

程序只读取导弹参数，不会修改原始文件。

## 一个典型算例

例如：

```text
导弹：AIM-120A
高度：6.5 km
发射方速度：1200 km/h
目标速度：1200 km/h
初始距离：15 km
离轴角：38°
目标姿态：迎头
```

程序会一直积分到：

- 命中 / 近炸引信触发
- 脱靶
- 超时
- 撞地

为止。

当前冻结的 AIM-120A 回归算例中，这组条件得到：

```text
12 m 近炸引信触发
t = 17.243 s
```

## 模型大概怎么工作

导弹采用一个简化的 **5 自由度刚体模型**。

平动部分计算导弹质心运动，转动部分计算 pitch 和 yaw，姿态使用四元数表示。

气动力模型是 reduced-order 的，而不是完整 CFD 或高维气动数据库：

```text
datamine 中的导弹参数
        +
统一的 Mach 阻力模型
        +
迎角相关横向气动力
        +
附加阻力
```

制导和控制是分开的：

```text
制导律
  ↓
期望横向加速度
  ↓
PID 自动驾驶仪
  ↓
舵面指令
  ↓
导弹动力学
```

大离轴发射时，模型还会先执行一个短暂的初始转向，把弹头转向预测遭遇区域，然后再进入正常比例导引。

完整方程、参数解释以及每个假设背后的证据都放在：

[`docs/UPDATE_V1.0.1.md`](docs/UPDATE_V1.0.1.md)

README 这里只介绍模型结构，不展开所有考据过程。

## 能信到什么程度？

目标是：

**得到物理上自洽、能够做工程比较的结果。**

不是：

**逐帧复刻游戏内部求解器。**

目前有一些可以拿来做 sanity check 的锚点。

| 算例 | 模型 | 游戏 / 外部结果 |
| --- | ---: | ---: |
| 35 km 迎头拦截 | 33.26 s | 32.77 s |
| 单帧过载对比 | 15.9 G | 15.0 G |
| AIM-120A，15 km / 38° | 17.243 s | 16.7 s |

在目前已经测过的条件下，模型的过载—迎角关系与回放数据也能比较好地对上。

这些结果说明模型抓住了一些主要动力学，但还不足以把它称为“已验证的游戏模型”。

## 哪些东西还是推测？

并不是所有东西都能从 datamine 里直接读出来。

目前比较大的不确定项包括：

- 标定区间之外的精确阻力律
- 不同导弹是否应该共用同一个升力比例系数
- 惯导阶段游戏内部真正使用的姿态控制逻辑
- 精确的转动阻尼
- 推力随高度 / 外界气压变化的规律

这些部分会明确标出来，不会假装成已知参数。

详细证据和被排除过的其他解释见：

[`docs/UPDATE_V1.0.1.md`](docs/UPDATE_V1.0.1.md)

## 已知限制

目前没有建模：

- roll 动力学
- 燃料消耗导致的质心移动
- 精确转动惯量张量
- 舵机速率限制
- 完整非线性气动数据库

下面这些工况目前也没有经过系统验证：

- 长时间低速滑翔
- 极限尾追
- 目标持续高机动
- 完整远程爬升弹道

另外还有一个已经知道的 mismatch：

2.57 之后，游戏中的火箭发动机推力似乎会随外界气压变化。

例如一组 6.8 km 高度的回放反推出，续航段实际推力比 datamine 标称值高约 16%。

目前数据还不足以重建这个规律，所以暂时没有加入模型。

## 导弹支持情况

`missiles/` 里目前有 120 个导弹参数文件。

其中：

- **116 个**可以使用当前模型运行
- **4 个**暂不支持

剩下四个使用指令制导或驾束制导，和当前空空导弹使用的制导模型不是一套物理。

程序遇到这些导弹时会明确返回：

```text
Unsupported physics
```

而不是偷偷套一个错误的比例导引模型。

## 回归测试

AIM-120A 有两组固定算例，用来检查代码或配置有没有被意外改坏。

统一使用：

```text
dt = 0.02 s
```

| 条件 | 结果 | 时间 |
| --- | --- | ---: |
| 12 km，10° 离轴，迎头 | 12 m 引信触发 | 10.553 s |
| 15 km，38° 离轴，迎头 | 12 m 引信触发 | 17.243 s |

这两组算例使用的是冻结的 v1.0.0 配置：

```text
configs/aim120a_h2.yaml
```

v1.0.1 的新动力学走另一条运行路径。

两者故意分开，这样继续改新模型时，不会悄悄改变已经冻结的回归基准。
