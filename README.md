# missile_sim

> 战争雷霆导弹飞行仿真 · 独立本地候选模型

`missile_sim` 是一个可审计的 Python 导弹飞行仿真工作台。它把导弹 profile、目标场景、制导/控制和数值仿真分开，方便查看轨迹、比较假设，并导出可复查的结果。

> 非官方项目，不隶属于游戏开发商；不声称复现游戏内的专有飞行求解器。

| 状态 | 说明 |
|---|---|
| 模型 | `Experimental` 本地候选 |
| 运行时 | Python 3.10+，核心无第三方运行依赖 |
| GUI | 本机 `127.0.0.1`，不调用外部 API |
| 当前冻结基线 | AIM-120A `v1.0.0` |

## 快速开始

在项目根目录运行：

```powershell
# 运行标准库回归入口
py -3 scripts\run_test_functions.py

# 启动本地交互界面
.\run_gui.cmd
```

GUI 只读取 `missiles/*.json`，在内存中执行仿真。它提供三维轨迹、二维遥测、场景/结果 JSON 与轨迹 CSV 导出；不会修改导弹 profile、游戏文件或历史实验数据。

## 能做什么

- 从 JSON profile 加载质量、发动机、几何、气动、制导与 PID 参数；
- 模拟两段固体火箭、连续质量变化、标准大气与三维目标运动；
- 使用 PN / PN-loft、加速度 PID 和舵机响应生成候选飞行轨迹；
- 记录推力切段、燃尽、近炸、撞地、寿命、航程和数值失败等终止事件；
- 为可运行的常规舵面、固体火箭、PN 或 PN-loft profile 提供统一的 `profile_h2_universal_v2` 运行路径；
- 对不属于该模型范围的指令制导或驾束制导导弹明确标为 `Unsupported physics`，不会静默改用 PN。

## 模型边界

这里的结果是**本地工程候选**，适合比较设定、检查时间域行为和生成诊断数据，而不是宣称游戏内飞行模型的真值。

- 有效阻力面积、升力/Mach 形状、loft/control 都是可审计的候选解释；
- AIM-120A 的冻结案例是回归锚点，不等价于全包线验证；
- 不把单一外部读数、UI 文案或公开客户端代码当作专有方程的证明；
- 未建立：长时间低速滑翔、极端尾追、持续机动目标、完整 loft、六自由度滚转，以及与游戏内模型的端到端等价性。

## 目录一览

```text
src/aim120_model/       仿真内核与公共 API
src/missile_gui/        仅本机访问的 GUI
missiles/               单枚导弹的单位明确 profile
scenarios/              发射与目标条件
config/ + configs/      数值默认值与冻结配置
schemas/                profile 校验规则
scripts/                运行、导入、诊断与发布工具
tests/                  回归与契约测试
```

`data/raw/`、`outputs/`、`dist/` 与 `.md/` 是本地证据、生成物或内部文档，不进入 Git 仓库。

## AIM-120A 冻结回归锚点

固定步长为 `0.02 s`。以下两组目标条件用于发现代码或配置漂移：

| 条件 | 终止事件 | 本地时间 |
|---|---:|---:|
| 1200 / 1200 km/h，6.5 km，高度差 12 km，10° 离轴，迎头 | 12 m 近炸 | 10.553 s |
| 1200 / 1200 km/h，6.5 km，高度差 15 km，38° 离轴，迎头 | 12 m 近炸 | 17.243 s |

这些锚点是回归测试，不是未覆盖条件下的精度承诺。
